# Contributing

Thank you for helping improve GSN Contru.

## Development workflow

1. Fork the repository.
2. Create a feature branch:
   ```bash
   git checkout -b feature/your-change
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the app locally:
   ```bash
   npm run dev
   ```
5. Validate the production build before opening a PR:
   ```bash
   npm run build
   ```

## Code standards

- Keep the code clean and readable.
- Prefer simple, modular components.
- Maintain consistent naming and spacing.
- Avoid unnecessary dependencies.

## Pull requests

- Keep PRs focused on a single goal.
- Include a clear summary of changes.
- Mention any screenshots or demos when relevant.
- Ensure lint and build checks pass.
